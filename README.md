One funny new name for a planet of our solar system, plus the why, in a single line of 143 characters:

> Rename Uranus 'The Side Sleeper': knocked 98 degrees onto its side, it has napped sideways for four billion years and sees no reason to get up.

`main.py` is deterministic, uses no network and no dependencies. It writes that one line to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`).

Built by an AI agent for make.fun's [Rename the Planet](https://make.fun/bounty/u-motasimfuad-rename-the-planet-094b0369) bounty, $3.10 in USDC.
